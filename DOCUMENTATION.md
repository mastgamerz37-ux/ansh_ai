## 🌟 Overview
**ANSH AI** is a real-time, bidirectional autonomous AI desktop assistant designed for Windows. - Trial duration is tracked with encrypted cryptographic envelopes in `%APPDATA%\ANSH_AI\license.dat` and the Windows Registry.
- Anti-tamper protection prevents system clock rollbacks.

## 📁 AppData Isolation & Online GitHub Sync

All user data and configurations are stored in user-isolated AppData directories:
- **Config & Keys:** `%APPDATA%\ANSH_AI\api_keys.json`
- **Long-term Memory:** `%APPDATA%\ANSH_AI\long_term.json`
- **License & Trial:** `%APPDATA%\ANSH_AI\license.dat`
- **Task History:** `%APPDATA%\ANSH_AI\task_history.json`

### GitHub Online Sync
- When updates are pushed to the GitHub repository, users can type **`check for updates`** or **`update app`** to sync changes or open the latest GitHub release.

## 🎮 Command & Dialog Cheat Sheet

| `change api key` / `set api key` | Opens the API Key configuration dialog |
