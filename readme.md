## ⚡ Quick Start

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/devanshu/ANSH-AI.git
cd ANSH-AI
pip install -r requirements.txt
```

### 2. Launch ANSH AI
```bash
python main.py
```
*(On first launch, enter your Google Gemini API Key and your name in the setup dialog).*

## 🚀 Key Features

- **Smart Floating Island:** Fluid dynamic island UI with voice subtitles, hotkey (`Ctrl+Shift+A`), and live liquid animations.
- **PowerPoint Presentation Maker:** Generates complete 3-50 slide decks with Morph transitions, Gemini editorial assets, and native 3D models.
- **Deep Research Engine:** Multi-query investigation, scraping, and in-memory citation reports.
- **Autonomous Developer Agent:** Multi-file project planner, automated dependency installer, and self-healing runtime debugger.
- **Universal File Processor:** OCR, conversion, summarization, Excel/CSV analysis, audio/video processing.
- **Media & Spotify Control:** Seamless playback control for Spotify, Apple Music, YouTube Music, and system players.
- **Gmail & Messaging:** Google OAuth client discovery, approval-gated email drafting, Instagram DM automation.
- **AppData Isolation:** All user configurations, keys, memories, and license states are stored securely in `%APPDATA%\ANSH_AI`.
- **Developer Attribution:** Asking about the developer triggers spoken response and automatically opens [https://devanshu.page.gd](https://devanshu.page.gd).
